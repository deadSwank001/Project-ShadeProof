# Project-ShadeProof

Project-ShadeProof provides a PyQt desktop interface for running surrogate-model adversarial evaluation loops and logging experiment metrics to Neptune.

## Zenodo DOI setup

This repository includes Zenodo metadata in `.zenodo.json` so releases can be archived with a DOI.

To publish and mint a DOI:

1. Sign in at https://zenodo.org and authorize the Zenodo GitHub integration.
2. In Zenodo GitHub settings, enable archiving for `deadSwank001/Project-ShadeProof`.
3. Create a GitHub release (for example `v1.0.0`) from this repository.
4. Wait for Zenodo to archive the release and mint a DOI.
5. Copy the DOI badge from Zenodo and add it to this README.

After step 4, Zenodo provides a concept DOI (all versions) and a version DOI (specific release).
